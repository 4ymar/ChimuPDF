## 📋 Descripción

**ChimuPDF** es una aplicación de escritorio para visualizar y organizar documentos PDF. Permite abrir un archivo, recorrer sus páginas con un panel de miniaturas, y reorganizar su contenido: rotar, eliminar y reordenar páginas, insertar otros PDF, unir varios archivos en uno o dividir un documento en varios. Incluye búsqueda de texto y reconocimiento óptico de caracteres (OCR) en español e inglés.

Desarrollada bajo la marca **GiraDevs**.

---

## ⚡ Funcionalidades principales

| Módulo | Descripción |
| --- | --- |
| 📂 **Abrir documentos** | Apertura desde el menú, arrastrando y soltando el archivo, o desde la línea de comandos. Pantalla de inicio con acceso a archivos recientes |
| 🔍 **Visualización** | Acercar, alejar, tamaño real, ajuste al ancho, ir a una página concreta y panel de miniaturas |
| 🔎 **Búsqueda** | Búsqueda de texto dentro del documento (`Ctrl+F`) |
| 🔄 **Rotar páginas** | Rotación a la izquierda o a la derecha |
| 🗑️ **Eliminar páginas** | Eliminación de las páginas que no se necesitan |
| ↕️ **Reordenar páginas** | Arrastrando las miniaturas o con los atajos `Alt+↑` / `Alt+↓` |
| ↩️ **Deshacer y rehacer** | Historial de cambios sobre el documento |
| ➕ **Insertar PDF** | Inserción de otro PDF al final, antes o después de la página actual |
| 🧩 **Unir PDF** | Combina varios archivos PDF en uno solo |
| ✂️ **Dividir PDF** | Separa un documento en varios archivos |
| 🔤 **OCR** | Reconocimiento de texto en español e inglés |
